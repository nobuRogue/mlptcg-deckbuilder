# 議事録：開発方針決定

- 日付: 2026-10-01

## 決定事項

| 項目 | 決定 |
|---|---|
| 形態 | Web アプリ |
| 利用者 | 仲間内で共有 |
| v1 機能 | 検索・絞り込み / デッキ枚数・構築ルールチェック / 保存・共有 |
| v1 対象外 | 分析グラフ・試し引き（v2 以降で検討） |

## 技術構成（案）

- フロント: Vite + React + TypeScript（ビルド結果は静的ファイルのみ、サーバー不要）
- カードデータ: Node スクリプトで公式 cardlist ページの `__NEXT_DATA__` から抽出し
  `cards.json` としてリポジトリに同梱。新弾追加時にスクリプトを再実行して更新。
- カード画像: 公式ストレージの URL を直接参照（画像はコピー・再配布しない）
- 保存: ブラウザの localStorage
- 共有: デッキ内容を URL に埋め込む（例: `#deck=<エンコード文字列>`）＋テキスト書き出し
- 公開: GitHub Pages など無料の静的ホスティング（URL を知っている仲間だけが使う運用）
- バージョン管理: Git（導入済み 2.28）

## 未決事項

- デッキ構築ルールの確定（コアルール PDF の確認が必要）
- ソースコードの配置場所（本ディレクトリ配下にするか別にするか）
- 公開先（GitHub Pages 等）とアカウント
