# 調査メモ：公式カードリストのデータ構造

- 調査日: 2026-10-01
- 対象: https://www.mlptcg-jp.com/cardlist

## 結論

- 公式サイトは Next.js 製。カード全件（600件）が HTML 内の `__NEXT_DATA__` JSON
  （`props.pageProps.site.cards`）に埋め込まれている。
- ページ送り・API 呼び出しは不要で、**cardlist ページを1回取得すれば全カードを JSON で抽出できる**。
- カード画像は外部ストレージ（`jp-web-1311229882.cos.ap-tokyo.myqcloud.com`）上の PNG。
